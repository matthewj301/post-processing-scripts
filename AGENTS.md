# Repository Rules

## Commit messages and attribution

- No commit message may name or reference Claude, in any form, anywhere in the
  subject, body, or trailers. This applies to every commit created for this repo,
  regardless of branch, worktree, remote, or destination, including merge,
  squash, cherry-picked, amended, and release commits.
- Do not add co-author attribution or `Co-authored-by` trailers. Do not add
  assistant attribution, generated-by notices, signatures, or equivalent credits
  to commit messages.
- Check the complete final commit message before creating or amending a commit,
  including any automatically generated text or trailers.
